# 学位论文自动审查系统需求文档

日期：2026-11-16　状态：当前实现与待确认需求

## 1 目标与范围

辅助评审人员检查学位论文写作、格式与部分语义逻辑问题，输出可回溯的问题提示，由人工核对后生成最终报告。当前范围是负面清单第 2–38 条共 37 项，尚未完整实现数据可信度、AI 内容可靠性、规范逻辑和创新价值四维学术审查。

部署要求：论文在本地或内部环境处理；接入参数量大于 8B 的内部模型；现有单张 A100、低并发；使用本地目录存储。模型、规范来源及内网隔离需要分别验收，不以网页运行成功代替业务验收。

## 2 用户流程

上传论文，选择学位层次并填写可选重点 → 排队检查 → 查看问题、37项状态、上下文和原页 → 勾选划除 → 保存选择并生成独立最终报告。原始报告和已生成的快照保留。

评审人员核查意见；规范维护人确认条款来源及适用性；领域专家评价实质问题；管理员负责模型、网络和数据管理。系统尚无账号、角色和正式审计功能。

## 3 当前功能

| 编号 | 功能 | 已实现 | 限制 |
| --- | --- | --- | --- |
| R01 | 材料输入 | PDF/DOCX/TXT/PNG/JPG/JPEG上传；API文本输入；原件下载 | 页面要求文件；图片只保存，无OCR；扫描件可能没有可读正文 |
| R02 | 尺度和重点 | 学位层次、额外重点实际参与；保留阶段和语种字段 | 阶段／语种未驱动完整分支，主要输出中文；无独立专业学位字段 |
| R03 | 参考规范 | 上传、选用、提取并保存 | 尚未参与动态规则或模型上下文，无发布、版本和适用性管理 |
| R04 | 清单检查 | 9项确定性、14项版面、14项语义检查 | 包含经验阈值和有限启发式，不能声称全部可靠自动判断 |
| R05 | 语义覆盖 | 部分规则分片阅读、核对返回记录、候选复核 | 其他任务可仅检查部分片段；阅读记录不等于理解正确 |
| R06 | 原文证据 | 多位置、偏移、上下文、区域和PDF截图 | verified仅表示来源匹配；文档树与截图以首份材料为主 |
| R07 | 任务管理 | 串行队列、查询、取消、失败记录、重启中断标记 | 无续跑；已发出的模型请求可能继续；部分批次并发2个请求 |
| R08 | 报告与复核 | JSON/Markdown、矩阵、划除、哈希／修订冲突检查、独立快照 | 划除不等于规则通过；原始与最终结论阈值不同 |
| R09 | 持久化 | 本地原件、任务、复核、报告和模型调用记录 | 单进程锁，无多文件事务、跨进程锁、权限或生命周期管理API |
| R10 | 公开查询 | 用户批准手填query后查询Crossref元数据 | 与论文工作流独立，不自动查证或入报告，非隔离网关 |
| R11 | 四维学术检查 | 目前覆盖规范、部分逻辑和重复文字提示 | 实验数据、泄漏、公平比较、事实／文献真实性和创新评价未完整实现 |

### 检查分组

| 分类 | 规则号 | 内容 |
| --- | --- | --- |
| 确定性 | 2、12、17–20、24、35、36 | 重复文字、公式编号、引用与文献、图表引用、标点、用语 |
| 版面 | 5、15、22、23、25–34 | 篇幅、字号、分辨率、题注、标题衔接、留白、段落与字体 |
| 语义 | 3、4、6–11、13、14、16、21、37、38 | 双语对应、综述、研究问题、章节关系、动机、符号说明、内容雷同、标题内容与连词 |

规则2、7、13、14、16、21、22、25、27存在覆盖局限，程序可能将“通过”调整为“无法可靠判断”。有37行状态不表示37项均已可靠完成。

## 4 输出与判断边界

总体判断采用“基本满足／需修改／存在重大问题／信息不足”。问题按严重度和规则号排序，包含分类、核实状态、位置与原文、问题、建议及可选测量值。附逐项状态、优先事项和检查限制。

规则状态为发现问题、检查通过、不适用、缺少输入、无法可靠判断、执行失败；人工划除可显示“问题提示已划除”。无法定位的内容不得虚构出处，可保留待核实提示。

无原始材料不得认定造假，不凭文风认定AI代写或给出比例；未核实相关工作不否定创新。未取得具体教育部、国科大、信工所及培养规范时，不编造条款或声称完成合规核验。

## 5 已知限制和后续工作

| 项目 | 当前行为 | 待完成 |
| --- | --- | --- |
| 结论口径 | 原始报告major≥3判重大；最终报告保留major≥1即判重大 | 确认是否统一及具体标准 |
| 全文覆盖 | 部分规则分片，无统一全文预算保护；PDF警告或未可靠完成规则使partial | 完善上下文预算、跨章覆盖和范围说明 |
| 输入与证据 | 无OCR；DOCX特殊内容、复杂公式、多材料定位有限 | 本地OCR／视觉解析和可靠定位 |
| 参数与规范 | 阶段、语种和规范文件没有完整评审执行分支 | 根据适用规范落实尺度与语言 |
| 隐私与运维 | 模型地址由管理员指定，图云追踪关闭，本地日志含原文 | 身份、出站策略、保留、删除、备份及恢复 |

默认上传100MiB、文本API上限100万字符；超限提示仍有“30MB”文字。completed表示流程完成，不表示论文通过。

## 6 联网选择

| 模式 | 路径 | 能力限制 |
| --- | --- | --- |
| 严格隔离，待建设 | 与当前论文无关的公开资料预设同步，批准导入内网检索 | 不提供任务驱动的实时公网查询，受资料更新范围限制 |
| 受控联网，待建设 | 精确查询批准 → 独立网关 → 公共来源 → 清洗与内网核查 | 查询组合可能泄露方向，需授权和目标限制 |
| 当前 | 手填query、approved=true，由应用直接查询Crossref | 只取元数据，不等于以上隔离方案已部署 |

论文原文、内部题目、数据、图片和完整提示词不得发送给公网模型或搜索；OCR、日志、备份和前端资源同样纳入边界。

## 7 验收与待确认项

工程验收覆盖接口契约、完整审查输出、规则正反例、阅读覆盖、跨页与公式、截图、取消、复核冲突和快照。当前25个回归套件通过，使用构造样本、临时目录及模型替身；未验收真实模型准确率、A100性能、真实论文召回和内网隔离。

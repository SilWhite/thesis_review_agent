# 学位论文自动审查系统需求文档

日期：2026-11-16　状态：当前实现与待确认需求

## 1 目标与范围

辅助评审人员检查学位论文写作、格式与部分语义逻辑问题，输出可回溯的问题提示，由人工核对后生成最终报告。当前范围是负面清单第 2–38 条共 37 项，尚未完整实现数据可信度、AI 内容可靠性、规范逻辑和创新价值四维学术审查。

可选补充范围：联网创新性初判，以及论文、实验配置、数据、代码和结果的交叉一致性审查。补充报告独立于原 37 项评审，不调整其接口、规则和总体结论；不要求实验复现，不执行作者代码，不认定造假或 AI 生成比例。

部署要求：论文在本地或内部环境处理；接入参数量大于 8B 的内部模型；现有单张 A100、低并发；使用本地目录存储。模型、规范来源及内网隔离需要分别验收，不以网页运行成功代替业务验收。

## 2 用户流程

统一首页选择已有论文或上传一次 → 勾选规范与逻辑／创新性初判／实验材料 → 填写对应参数与配套材料 → 一次点击提交 → 同页按论文查看全部任务 → 页签选择类别和历史报告。规范报告保留问题、37项状态、上下文、原页、人工划除及独立最终报告；补充报告保持自己的证据和判断口径。原始报告和快照保留。

评审人员核查意见；规范维护人确认条款来源及适用性；领域专家评价实质问题；管理员负责模型、网络和数据管理。系统尚无账号、角色和正式审计功能。

## 3 当前功能

| 编号 | 功能 | 已实现 | 限制 |
| --- | --- | --- | --- |
| R01 | 材料输入 | PDF/DOCX/TXT/PNG/JPG/JPEG上传或复用已上传论文；API文本输入；原件下载 | 补充审查每次一份可提取文本的论文；图片只保存，无OCR |
| R02 | 尺度和重点 | 学位层次、额外重点实际参与；保留阶段和语种字段 | 阶段／语种未驱动完整分支，主要输出中文；无独立专业学位字段 |
| R03 | 参考规范 | 上传、选用、提取并保存 | 尚未参与动态规则或模型上下文，无发布、版本和适用性管理 |
| R04 | 清单检查 | 9项确定性、14项版面、14项语义检查 | 包含经验阈值和有限启发式，不能声称全部可靠自动判断 |
| R05 | 语义覆盖 | 部分规则分片阅读、核对返回记录、候选复核 | 其他任务可仅检查部分片段；阅读记录不等于理解正确 |
| R06 | 原文证据 | 多位置、偏移、上下文、区域和PDF截图 | verified仅表示来源匹配；文档树与截图以首份材料为主 |
| R07 | 任务管理 | 串行队列、查询、取消、失败记录、重启中断标记 | 无续跑；已发出的模型请求可能继续；部分批次并发2个请求 |
| R08 | 报告与复核 | JSON/Markdown、矩阵、划除、哈希／修订冲突检查、独立快照 | 划除不等于规则通过；原始与最终结论阈值不同 |
| R09 | 持久化 | 本地原件、任务、复核、报告和模型调用记录 | 单进程锁，无多文件事务、跨进程锁、权限或生命周期管理API |
| R10 | 公开查询 | 原/search接口：用户批准手填query后查询Crossref元数据 | 此旧入口仍与论文工作流独立，不自动入报告；补充审查见R12 |
| R11 | 四维学术检查 | 目前覆盖规范、部分逻辑和重复文字提示 | 实验数据、泄漏、公平比较、事实／文献真实性和创新评价未完整实现 |
| R12 | 创新性初判 | 手填并批准最多3条查询；Crossref候选书目／摘要；关联论文引文与相关工作，输出初判 | 非全面查新，不抓取全文；无摘要只提供候选；不保证召回或语义判断正确 |
| R13 | 实验材料关联 | 每任务一份论文、最多10个实验，每实验最多20份配套文件；用户指定论文片段与文件关系 | 页面一次一个实验；片段须匹配提取原文；关联正确性、版本与完整性需人工确认 |
| R14 | 材料交叉核对 | 配置字段、Python字面量赋值、结构化数据数量、训练／测试ID重叠、有限指标数值、模型双侧引文分析 | 默认值不等于实际配置；相同ID不等于泄漏；不执行脚本，不推断原始数据真实来源 |
| R15 | 补充报告与任务 | 独立JSON／Markdown、来源和事实、问题与待核实建议；共用队列、取消及重启中断 | 尚无补充报告的人工划除／最终快照；不自动合并进37项报告 |
| R16 | 统一工作台 | 单页准备材料、可选三类审查、原件复用、按论文归集全部任务、页签与历史版本、取消和下载 | 按论文首份材料ID归集，不新增父任务；各链路独立接受、失败或取消，不提供跨任务事务 |

### 检查分组

| 分类 | 规则号 | 内容 |
| --- | --- | --- |
| 确定性 | 2、12、17–20、24、35、36 | 重复文字、公式编号、引用与文献、图表引用、标点、用语 |
| 版面 | 5、15、22、23、25–34 | 篇幅、字号、分辨率、题注、标题衔接、留白、段落与字体 |
| 语义 | 3、4、6–11、13、14、16、21、37、38 | 双语对应、综述、研究问题、章节关系、动机、符号说明、内容雷同、标题内容与连词 |

规则2、7、13、14、16、21、22、25、27存在覆盖局限，程序可能将“通过”调整为“无法可靠判断”。有37行状态不表示37项均已可靠完成。

## 4 输出与判断边界

总体判断采用“基本满足／需修改／存在重大问题／信息不足”。问题按严重度和规则号排序，包含分类、核实状态、位置与原文、问题、建议及可选测量值。附逐项状态、优先事项和检查限制。

规则状态为发现问题、检查通过、不适用、缺少输入、无法可靠判断、执行失败；人工划除可显示“问题提示已划除”。无法定位的内容不得虚构出处，可保留待核实提示。

无原始材料不得认定造假，不凭文风认定AI代写或给出比例；未核实相关工作不否定创新。未取得具体教育部、国科大、信工所及培养规范时，不编造条款或声称完成合规核验。

## 6 联网选择

| 模式 | 路径 | 能力限制 |
| --- | --- | --- |
| 严格隔离，待建设 | 与当前论文无关的公开资料预设同步，批准导入内网检索 | 不提供任务驱动的实时公网查询，受资料更新范围限制 |
| 受控联网，待建设 | 精确查询批准 → 独立网关 → 公共来源 → 清洗与内网核查 | 查询组合可能泄露方向，需授权和目标限制 |
| 当前 | 旧入口手填query、approved=true；补充入口public_queries、search_approved=true | 应用直连Crossref书目／可用摘要，不等于以上隔离方案已部署 |

论文原文、内部题目、数据、图片和完整提示词不得发送给公网模型或搜索；OCR、日志、备份和前端资源同样纳入边界。

## 7 验收与待确认项

## 8 补充审查尺度与当前限制

创新性输出“初步支持存在研究贡献／创新差异尚不清楚／信息不足”，基于有限候选解释差异，不输出创新评分，不因未检索到相关工作而认定有创新。引用文献从实际检索记录生成，模型只能选择登记的来源并引用已取得片段。截止日期可选；设置后，日期缺失或不完整的候选不纳入比较，可能降低召回。

实验审查围绕指定实验联系材料：论文描述 ↔ 配置／代码 ↔ 数据及划分 ↔ 结果。支持UTF-8文本文件，单份最多10MiB；不读取压缩包、Notebook、二进制权重、原始图片／音频数据，不连接远程代码仓库。代码附录可作为说明文本输入，不能据片段缺少实现认定方法未实现。

确定性比较只覆盖epochs、batch_size、learning_rate、train/test/validation_count、accuracy、macro_f1及其少量别名；论文字段依赖有限中英文模式，复杂表格和其他指标主要依赖模型阅读。结构化数据支持CSV、JSON记录数组、JSONL；只有明确划分才生成对应数量，只有完整的指定ID列才检查重叠。统计记录数不一定等于独立样本数。accuracy和macro_f1按0–1或论文显式百分数核对，并允许论文显示精度内的舍入误差。

所有数值差异输出待核实：核对有效配置、覆盖关系、分片、版本、单位和统计口径；模型语义问题必须有双侧可匹配引文。未发现问题仅限已读材料，缺失、截断、模型／检索失败不得当作检查通过。模型解释仍可能出错，证据匹配不是事实或推论验证。

每实验模型可见文本总计最多30000字符、每来源最多12000字符，按论文片段及文件顺序分配；截断写入限制。创新性论文最多前24000字符，候选摘要每篇最多2000字符。未进行完整阅读覆盖证明，较长材料需人工缩小实验片段或拆分任务。

未披露的生成数据流程、结果硬编码等只可作为疑点；初始化、数据增强、已声明模拟数据和绘图常量均可能合理。材料一致也无法排除一致编造。不以统计异常或模型文风判断数据虚构，不声称已验证材料真实性。

后续：领域专家样本与误报评估、更多配置及启动命令覆盖关系、复杂表格与指标、多语言／大数据分块阅读、更多文献来源及全文证据、补充报告人工复核、受控出站网关。训练重跑和论文复现不属于当前范围。

工作台使用边界：只勾选的检查会提交；联网仍需对精确查询批准。选择规范与补充审查会创建两个原有后台任务，创新性和实验同时选择则合为一个补充任务。取消该补充任务会取消其中两项；取消规范任务不影响补充任务。各页签默认选择本论文该类别最新任务，可选旧版本；后来的失败任务不自动回退展示旧成功报告。不同版本须按时间和任务ID区分，不暗示是同一次执行。

当前不分页、不删除历史、不提供跨任务统一最终报告或总体通过结论。文件上传缓存仅在当前页面有效；刷新后复用服务端已有论文，不提供全局内容哈希去重。旧多论文规范任务按第一份论文归集，并标注原材料数量。
